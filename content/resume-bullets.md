## Portfolio / resume bullets (AJSIEM)

- Set up and implemented a robust Security Information and Event Management (SIEM) system leveraging Ubuntu Server, OpenSearch, MongoDB, Graylog, and Kali Linux.
- Orchestrated the configuration of Kali Linux to seamlessly transmit its logs to the Ubuntu server, optimizing data collection.
- Utilized OpenSearch to meticulously filter home network traffic (`HOME_NET` flows), subsequently presenting the refined data through the Graylog web interface and a live AJSIEM dashboard (devices, top talkers, protocol mix).
- Implemented a comprehensive alert system, stratified from low to high alert levels, to promptly identify and respond to specific types of network activity.
